# Storey (runtime)

Bake-only runtime for procedural buildings with walk-in interiors. Consumers of baked districts need only this package. Authoring lives in `com.triband.storey.authoring`; the reference character, camera and lift UI live in `com.triband.storey.playkit`.

Design and behaviour are specified in `docs/SPEC.md` at the repository root; the port plan is `docs/UNITY-PACKAGE-PLAN.md`. Anything not yet listed in `CHANGELOG.md` is not implemented.
