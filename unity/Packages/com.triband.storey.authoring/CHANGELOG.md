## [Unreleased]

### Added
- **Assets > Storey > Map Colours to Palette...** (docs/COLOURS.md §3.8): maps a layout's CSS colours to Color Pipeline palette entries (nearest by the Model Remapper's similarity, picked, or added to the palette) and rewrites the `.storey` file with palette ids and its palette block. In the optional `Triband.Storey.Editor.ColorPipeline` assembly, compiled only with Color Pipeline 2.1.11 up to 3.0. Not yet run in an editor.
- `.storey` ScriptedImporter and **Tools > Storey > Import Prototype Layout...** (workstream 1).
- Package skeleton: editor assembly definition, smoke test (workstream 0).
